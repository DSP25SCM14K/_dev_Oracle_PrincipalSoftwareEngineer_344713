# Dev Kumar — Distributed Systems Portfolio

A responsive, single-page engineering portfolio with a custom animated distributed-cloud topology, architecture diagram, full experience history, and searchable project catalog.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Deploy

This site is plain HTML, CSS, and JavaScript. Publish the repository root with GitHub Pages; no build step is required.

## Files

- `index.html` — page content and inline system topology diagram
- `styles.css` — responsive visual design and animation
- `script.js` — background topology, rotating focus text, reveals, and project search

All professional profiles and project repositories link to their original destinations.
